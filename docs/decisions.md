# Decisões já fechadas

Data: 2026-02-28

## Produto e canal
- Canal único: WhatsApp.
- Provedor alvo: WhatsApp Cloud API (Meta).
- Operação MVP: 1 número de WhatsApp para todos os clientes.

## Comercial
- Entrada única: R$60 por cliente.
- Mensalidade padrão: R$20.
- Regra de indicação: ao atingir 6 indicações, mensalidade cai para R$10.

## Operação
- Meta de resposta: o mais rápido possível sem perder assertividade.
- Painel admin focado no dono da operação, com visão de:
  - ativos
  - online recente
  - novos
  - inativos
  - inadimplentes
- Requisito de bloqueio por inadimplência: cliente que não paga deixa de receber resposta.

## Pendente de decisão
- Gateway de cobrança final (recomendação técnica na próxima etapa).
- Infra de produção final (VPS ou cloud gerenciada).

## Retenção inicial aprovada
- Mensagens: 12 meses.
- Transações: 24 meses.
- Backups: 90 dias.
